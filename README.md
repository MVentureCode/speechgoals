# Nombre del proyecto: SpeechGoals 

## Objetivo del proyecto:
- Es una aplicación web desarrollada con Django cuyo propósito es ofrecer un catálogo estructurado de objetivos terapéuticos utilizados en intervención logopédica.
- A diferencia de una historia clínica, SpeechGoals no almacena datos de pacientes reales. Su función es servir como herramienta de consulta, organización y planificación para profesionales que intervienen en el lenguaje, el habla, la comunicación, la deglución y la voz.

## Características:
- Catálogo de objetivos terapéuticos.
- Clasificación por áreas (lenguaje, habla, comunicación, deglución, voz).
- Detalles de cada objetivo: descripción, criterios de logro, nivel y etiquetas.
- Sistema de colecciones para organizar objetivos según sesiones o programas.
- Panel de administración para gestionar contenido clínico.

## Tecnologías:
- Django
- Python
- HTML + Django Templates
